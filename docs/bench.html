Benchmarks

Radix and SparkJS 2.3.1 drawing the same 4 scans (546k to 10.0M splats) along the same camera path, each with its default settings. On WebGPU, Radix is 1.35× as fast as Spark on WebGL2.

Apple M3 Max, Google Chrome 154.0.8037.98, 1920x1080. All results and the method: the full report.

03 · Known gaps

Where Radix is behind

  • Re-sort stalls on WebGL2. Radix's worker-sort cycle (a keys pass, a readback, then the order's upload) runs in rendered frames, where Spark's worker sort shows almost no stalls.
  • Loading. From the start of loading a PLY to the first frame: Radix 0.3 to 2.2 s, Spark 0.1 to 1.6 s.
04 · Method

How it was measured

  • Both renderers load the same degree-0 PLY of each scan, so both draw degree-0 color only, and draw the same camera poses: held still, a level turn, then a tilted turn, orbiting objects and looking around inside scenes.
  • Frames are drawn one at a time, each timed until the GPU has finished it, after a warm-up of at least 3 seconds. Each configuration ran 5 rounds in a shuffled order, in a fresh tab, with the laptop's thermal state and a canary configuration checked between runs.
